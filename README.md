# 魂の結束 — 道中・ボス接続版

この版では、道中60体撃破後にボス戦へ進み、ボス撃破でクリアします。
ボスは提供された武将を基にGPTイメージで作成した透過素材。HP40。剣撃と炎竜の遠距離攻撃を使用。
HP、スキル残量、被ダメージ、与ダメージ、フィニッシュ数を引き継ぎます。
道中終了時は残った敵弾・スキル弾・ダッシュを解除します。
クリアタイムは道中とボス戦の通算時間（最初の走行開始演出込み、ボス登場・撃破演出と一時停止は除外）。
道中タイムは道中最後の敵を倒したフレームで固定。道中で失敗した場合は経過時間。

# 魂の結束

スマートフォンのブラウザで遊ぶ、主人公1人の背面視点アクションゲーム。

## 操作

- START：開始。音声はこの操作で有効になります。
- 入力なしで前進。敵の前線で停止して戦闘、撃破後に前進を再開。
- 左右スワイプ：3レーンを移動。
- 上スワイプ：1秒間、通常走行の2倍に加速。下スワイプ：手前へ後退。
- 通常攻撃・スキルのどちらでも、撃破後0.5秒以内の上スワイプでスーパーダッシュ（速度42、最大距離10）。敵の前線で止まります。判定時間は一時停止中には進みません。
- 防御アイコン長押し：被ダメージ半減。
- 水波斬：周囲のレーンを含む前方への横斬撃。
- 大陸斬：同じレーンへ進む縦斬撃。
- スキル外周：最大5回分の残量。1回分を5秒で回復。
- 接触時に通常斬撃を開始。0.24秒で1ダメージ、攻撃間隔2秒。通常攻撃による撃破はスキルフィニッシュに含めません。敵30体撃破でクリア。
- スコア：スキルフィニッシュ1体1,000点＋クリア時のみタイムボーナス（600,000÷クリア秒数、小数切り捨て、分母の下限1秒）。SS/S/Aは従来の被ダメージ評価です。
- STOP：一時停止。別タブへ移った場合も停止します。
- PC：矢印キーで移動、1・2でスキル、スペース長押しで防御。

## 開発

HTML / CSS / JavaScript、Canvas 2D、Web Audio API。ビルド不要。
`python -m http.server 8765` でローカル起動します。

`tests/combat.cjs` は Node.js と `@napi-rs/canvas` を使用し、攻撃タイミング・重複命中防止・一時停止・前線制限・固定敵構成・全30体クリアを確認します。

## 現状

立体モデルではなく2D素材による疑似3Dです。主人公は提供された透過済みボディモデルを使用します。水波斬8枚・大陸斬8枚を足元基準で再生し、4枚目から5枚目の切り替えに斬撃を同期します。衣装付きの完成キャラクター画像への置換は未実施です。
iPhone Safari実機での操作・音量は未確認です。

技名表示は、森のHUDに合わせた小さな半透明の深緑色ラベルです。文字はゲーム固有の「水波斬」「大陸斬」です。控えめに浮かび、フェードで出入りします。通常時の走行は既存ボディ画像の脚を関節ごとに動かす簡易アニメーションです。


自動走行・通常斬撃・加速・撃破後0.5秒判定・スコアは、依存ライブラリ不要の `node tests/running.cjs` で検証できます。

通常走行では主人公の足元が画面上端から58%の位置まで進み、以後カメラが追従します。加速・スーパーダッシュ中は53%の位置を目指します。画面上の前進も実際の移動距離に含まれ、攻撃や接触判定と一致します。主人公は1人です。

サンプル映像の構図に合わせ、遠景の消失点は画面上端26%、HPと顔アイコンは左下、操作アイコン3個はHP下、時間は上中央、STOPは右上へ配置しています。仲間用ボタンは追加していません。

速度感の調整：通常走行9、加速18、スーパーダッシュ42（ワールド単位/秒）。サンプル12〜16秒の地面模様追跡では、画面高さに対する流速の各1秒区間中央値は約0.20〜0.53/秒。通常走行の画面64%地点では約0.31/秒になるよう設定。地面は進行距離に同期した遠近投影のテクスチャ帯、遠景は固定。走行歩調も距離に同期。元動画との完全一致を保証する値ではありません。

水波斬の視覚表現：参考映像7.05秒付近からの水帯を時系列で再構成。身体の周囲を横に巻く帯、奥側に立ち上がる水膜、残留飛沫を、身体の前後2パスで描画。独立した飛翔三日月や追加の命中円は削除。ダメージ・射程・消費量は維持しています。元動画の音声は使用していません。

下部UIの見切れ対策：visualViewportの実表示領域にゲーム全体を合わせ、ツールバーの開閉時に再計算。ボタン下端に最低44pxの余白を確保。通常走行時の主人公は画面高約22%、足元58%の位置。iPhone実機未確認。

## リザルトと採点（本ゲーム用）

参考動画の結果表を再構成。弱点ダメージはユーザー指定により与ダメージへ変更し、オーバーキルを独立した加点欄にしました。

- クリアタイム：クリア時のみ floor(600000 / max(1, 秒数))。
- スキルフィニッシュ：1体1000点。
- 総被ダメージ：クリア時のみ max(0, 10000 - round(被ダメージ×500))。
- 与ダメージ：実際に敵HPを削った量×100点。超過分を含めない。
- オーバーキル：攻撃ダメージのうち敵の残りHPを超えた量×100点。通常攻撃・スキルの両方を集計。死体への再命中は加点しない。
- 合計：上記5項目の和。失敗時も実績の点数を表示するがハイスコアは更新しない。
- 評価：現ステージは1群（1/1）。クリア60秒以内SS、90秒以内S、120秒以内A、それ以外B。
- これまでのハイスコア：この採点方式専用のブラウザ保存値。保存できない環境でもプレイ可能。

元動画の非公開計算式のコピーではありません。結果画面は縦スクロールに対応し、OKで再プレイできます。
