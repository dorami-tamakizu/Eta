# 魂の結束 — 完成版

公開先：https://dorami-tamakizu.github.io/Eta/

道中60体を倒してボス戦へ進む、スマートフォン向けアクションゲームです。
上スワイプごとに一歩分の加速が積み重なります。撃破直後のスーパーダッシュは敵の束の間隔1つ分（32）までです。
ボスは前後左右へ移動し、スキル命中時のみダメージを与えます。主人公の後退に連動して巨大化しません。撃破数は画面表示しません。
スキルは元の命中判定と50%経過後のキャンセル受付です。連打予約や左レーンだけへの命中を中断する仕様はありません。

通常攻撃は1秒に1回・1ダメージで、GPTイメージ製の斜め振り下ろしエフェクトと同期します。ボスの横斬撃は表示中の接触も1発動1回まで判定し、炎竜は描画位置・幅を含めて命中判定します。防御による無効化は維持します。

## 配布ファイル

`index.html` が参照するハッシュ付き JavaScript が公開用です。`game.js`、`bgm.js`、`sfx.js` は保守用ソースで、対応する公開用ファイルと内容が一致します。
`assets/` には現行コードが参照する素材のみを収録しています。旧版はGit履歴に残り、公開ディレクトリには含めません。
背景の画像内容は維持し、ファイル名に内容ハッシュを付けています。背景の読み込み完了後にSTARTを有効化し、読み込み途中に旧背景を描く処理はありません。

## 検証

```sh
node tests/release.cjs
node tests/damage-total.cjs
node tests/title-menu.cjs
node tests/boss-hitbox.cjs
node tests/boss-random.cjs
node tests/running.cjs
node tests/boss-animation.cjs
node tests/swipe-movement.cjs
node tests/bgm.cjs
node tests/ultimate-audio.cjs
```

ローカル起動：`python -m http.server 8765`
音源の出典は `AUDIO_CREDITS.md`、ボス素材の出典は `assets/README-boss-contact-v6.md` を参照してください。

主人公の刀身は持ち手を基準に約12%長く、約30%太く描画します。立ち姿・攻撃・走行・防御の各フレームに位置を登録し、身体に隠れる刀身はそのまま隠します。

ボスの移動先・移動時間・歩調・スキル順・発動間隔は都度抽選します。移動は3レーン内、奥行き9〜15に収まり、予兆と命中モーションは維持します。ブラウザの乱数を独立に使うため、再プレイでも固定行動列には戻りません。

タイトル画面のメニューは「ゲーム説明」「ランキング」の2項目です。ランキングはSupabaseの全プレイヤー共通の上位100件です。クリア結果の「名前を入力してランキング登録」から任意の名前で投稿し、各記録の詳細で4項目の数値・得点とオーバーキルを表示します。ログインやプレイヤーIDはありません。`supabase/best-score-per-name.sql` 適用後の投稿は同名につき最高トータルスコア1件にまとめます。適用前の記録は変更・統合しません（既存の上位100件制限は継続）。同点・低得点は更新せず、高得点では内訳も一緒に更新します。SQL Editorでの実行が必要です。

ゲーム説明はGPTイメージ製の4ページ（ゲーム概要／スーパーダッシュ／ハイスコア／ランキング登録）です。矢印で移動し、全ページ共通の「閉じる」でタイトル画面に戻ります。画面サイズに合わせて画像全体を縮小表示します。

与ダメージは実際に削ったHP＋オーバーキル分です。全敵撃破時は214＋オーバーキルとなります。与ダメージスコアは round(与ダメージ × 100000 / 214) で、10万点の上限はありません。注記のオーバーキルは内数で、二重加算しません。奥義ゲージは有効HP分だけで回復します。

モバイル互換性：iOS SafariとAndroid Chrome向けにPointer Events、Visual Viewport、ユーザー操作時の音声開始を使用しています。タイトル文字は自動拡大を抑え、縦横の画面寸法で縮小し、1行表示します。古いブラウザ向けに100vhの高さフォールバックがあります。実機iOS／Androidでの通しプレイと音声確認は未実施です。

リザルトのOKはタイトル画面へ戻ります。STARTを押すまで次のプレイは始まりません。通常攻撃はフロントライン付近で正面の敵の有無によらず1秒ごとに振り、命中時点で正面の射程内にいる敵だけに1ダメージを与えます。スキル・奥義・防御中はそれらの動作を優先します。

共有ランキング：`ranking.js` が公開用キーとRLSで `public.rankings` に接続します。個人の過去の端末内記録は共有ランキングへ自動送信しません。投稿ボタンの二重操作を防止し、通信結果不明時は再送せずランキングで確認します。匿名投稿のため、改ざんされた値や別ブラウザからの連続投稿を完全には防止しません。

検証：`node tests/shared-ranking.cjs`（投稿、二重送信、詳細、名前のHTMLエスケープ、通信失敗、古い応答）。

ランキングは赤地・金枠・明るい記録カードのデザインです。現在の表示順位に応じ、1位は金杯と「覇者」、2位は銀杯と「英雄」、3位は銅杯と「達人」を表示します。称号は名前や保存データを変更せず表示時に付けます。

保存件数制限：Supabase SQL Editorで `supabase/retain-top-100.sql` を実行すると、登録・更新ごとに上位100件だけを残し、101位以下を削除します。既存の圏外記録も実行時に削除します。並び順は得点降順、登録日時昇順、記録ID昇順で表示と共通です。SQLの配置・公開だけではDB設定は適用されません。

ランキング詳細の道中クリアタイムは `supabase/add-road-time.sql` の実行後に保存します。未保存の過去記録は「未記録」。自己ベスト更新時は道中タイムも更新し、同点・低得点は保持します。旧DBでは道中タイムを省略して従来のスコア登録を継続します。

ランキングカードは2行構成（アイコン・順位・名前／称号とトータルスコア・点数・詳細）。4〜10位は🎖️と十傑、11〜30位は英傑、31位以降は称号なし。保存済みの名前・数値・内訳は変更せず表示だけを整形します。
