# ボス素材と演出

GPTイメージ（組み込み画像生成）で作成。参照：ユーザー提供の武将画像と8秒の動作動画。

- boss-warlord.png：1024×1536、透過RGBA。人物、衣装、剣のみ。
- boss-sword-atlas.png：1536×1024、透過RGBA。4列×2行、8ポーズ。
- boss-fire-dragon.png：1254×1254、透過RGBA。炎だけでできた竜の遠距離攻撃。

## 生成指示（要約）
1. 参照の黒髪、長い編み髭、青い目、黒赤金の鎧、竜の肩飾り、炎の曲刀を維持。背景の竜・地面・周囲の炎を除去し、人物と剣を透過背景に抽出。
2. 同一キャラクターでニュートラル、剣を上げる、頭上で構える、振り下ろす、振り抜く、余韻、戻す、ニュートラルの8コマ。全身と剣を各セルに収める。
3. 炎そのものでできた竜。画面手前へ向く頭、角、開いた口、S字の胴と尾。余分な背景を入れず透過。

## 現仕様
仮名称BOSS、HP40。通常は剣撃3ダメージ。遠距離または剣撃を重ねた後に炎竜4ダメージ。
攻撃予告レーンを表示。予告後は狙い直さない。剣撃・炎竜とも別レーンへの回避と防御が可能。
道中終了→クリア表示と前進→警告→ボスのアップ→戦闘。
ボス撃破→撃破位置・姿勢・大きさを維持し約1.6秒で透明化→QUEST CLEAR→フェード→リザルト。
演出中はタイマー、スキル回復、戦闘入力を止める。STOPで演出も一時停止。
