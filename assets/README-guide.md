# Game guide pages

Three 1024 × 1536 images generated with built-in ChatGPT Image and converted to WebP. The approved illustrations are displayed unchanged, with native HTML navigation and return controls.

Page 1 prompt: navy-and-gold fantasy tutorial card titled ゲーム概要, instruction 敵に接近してスキルや奥義を発動しよう！, orange-haired knight on a forest road using skills, footer 1 / 3.
Page 2 prompt: match page 1; スーパーダッシュ, swipe upward immediately after defeating an enemy, スキルが回復 and タイム短縮 benefits, footer 2 / 3.
Page 3 prompt: match page 1; ハイスコアを狙おう; four readable panels describing クリアタイム, スキルフィニッシュ, 被ダメージ and 与ダメージ, footer 3 / 3.

The 閉じる button on every page closes the guide and restores title-menu focus. It does not start combat.
