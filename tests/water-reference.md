7.10 / 7.20 / 7.30 / 7.40 / 7.50 / 7.60秒を実装の発生後
0.05 / 0.15 / 0.25 / 0.35 / 0.45 / 0.55秒と並べて目視比較した。
発生時刻は画面上の推定であり、元ゲーム内部の正確なフレーム番号ではない。

- 立ち上がり：左側から横に帯が広がる。0.06秒程度で身体を囲む幅まで展開。
- 0.10〜0.25秒：手前側に厚い水色の帯。奥側に縦の水膜と白い明部。
- 0.30〜0.45秒：手前の帯が先に細くなり、奥側の薄い水と残留粒子へ移行。
- 0.55〜0.60秒：残留粒子が消える。
- 描画順：水の奥側→主人公→水の手前側。単一の発生記録を共有。
- 以前の上下2枚の三日月・飛翔する水刃・追加の命中円は削除。
- 紫色・金色の別キャラクターの攻撃、ダメージ数字、UIは水エフェクトに含めない。
- 水波斬のダメージ、範囲、ヒット重複防止、スキルフィニッシュは既存値を維持。
